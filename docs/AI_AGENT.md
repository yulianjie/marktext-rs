# 写作 Agent

MarkText 内置一个 Rust 驱动的写作 Agent，默认提供 DeepSeek 预设。使用 Chat Completions 兼容协议，支持自定义服务地址、模型和本地 Ollama。模型需支持流式输出与工具调用。

## 为什么选择这个方案

| 方案 | 适用性 |
| --- | --- |
| **内置 Rust Agent + 兼容 API（采用）** | 复用现有 Tauri 后端，无须额外安装 Node/Python/CLI；文档上下文、工具权限、取消、审阅和撤销可直接融入编辑器。 |
| 外接 Codex / Claude CLI | 更适合整个代码仓库的任务；增加安装、登录和进程协议维护，通用文件操作也超出了写作助手当前需要。 |
| 前端直接访问模型 | 无法统一保护密钥，容易遇到跨域限制，也不利于管理取消和多窗口隔离。 |

使用应用自己维护的小型工具循环，避免额外引入完整 Agent 框架。DeepSeek 的[工具调用文档](https://api-docs.deepseek.com/guides/tool_calls/)描述了模型请求工具、应用执行、再把结果交还模型的流程。OpenAI 的[函数调用文档](https://developers.openai.com/api/docs/guides/function-calling)和 Ollama 的[兼容接口文档](https://docs.ollama.com/api/openai-compatibility)提供相应协议参考。

## 使用

1. 点击标题栏 **AI 助手**，或按 `Ctrl/Cmd+Shift+A`。也可在「视图」菜单或命令面板打开。
2. 点击面板齿轮进入「模型设置」。DeepSeek 预设使用 `https://api.deepseek.com` 和 `deepseek-flash`；模型名称可以按账号可用模型修改。OpenAI 地址预设为 `https://api.openai.com/v1`，Ollama 为 `http://localhost:11434/v1`，这两项需填写模型 ID。
3. 填入 API Key，点击「保存并测试」。本地 Ollama 可不填密钥，但需先运行服务并下载支持工具调用的模型。测试只发送一条测试消息。
4. 输入要求或选择润色、摘要、提纲、续写。输入框上方默认显示「当前文档 · 按需读取」。这表示允许按需访问当前快照；普通问答不会预先发送正文。在编辑器选中文字后，打开助手（包括 `Ctrl/Cmd+Shift+A`）或点击消息输入框，会自动附加选区。可展开预览核对文字、手动重新附加，或点击关闭按钮切回整篇文档；取消文档复选框后不会自动重新开启。源码和所见即所得模式都支持。
5. Agent 可查看文档提纲、搜索文字、按行读取相关段落，或提出一处连续 Markdown 替换。全文读取仅用于全文摘要、整体改写等任务。展开原文/建议对照后点击「应用修改」或「忽略」。生成期间不会更改编辑器。
6. 应用后可以「撤回」，也可通过编辑器正常撤销操作恢复。应用与撤回会检查文档快照；继续编辑后旧快照不能覆盖新内容。应用后的内容遵循现有保存/自动保存设置。

`Enter` 发送，`Shift+Enter` 换行。生成过程中可停止、切换文档或收起面板；每篇文档保留自己的对话。滚动查看旧消息时不会被强制拉回底部。窄窗口使用右侧浮层，面板支持键盘调整宽度，界面支持中文、英文、日文与内置主题。

### 图片输入

在消息输入框直接粘贴截图/图片，或点击「添加图片」选择 PNG、JPEG、WebP 文件。发送前可查看缩略图、点击放大、逐张移除；支持图片与文字一起发送，也支持只发送图片。普通文字粘贴仍使用输入框原来的行为。

- 每条消息最多 4 张图片，单张最多 5 MiB；整段对话最多 12 张、总计 20 MiB。超过限制会显示错误，不会悄悄丢弃图片。
- 图片随消息保留，用于后续追问和失败重试。未发送的图片、选区和文档附加开关按文档分别保存；异步读取图片期间切换文档不会把图片附加到另一篇文档。
- 图片仅在窗口内存保存，点击发送后由 Rust 通过兼容接口交给配置的服务。图片按 [OpenAI 官方图像输入协议](https://developers.openai.com/api/docs/guides/images-vision?api-mode=chat)编码为 `text` / `image_url` 内容数组，使用内嵌 Base64 图片；纯文本消息保持原协议。不把图片上传至另一个图床。
- 模型必须同时支持图片输入、流式输出和工具调用。连接测试目前只验证文本请求；供应商拒绝图片请求时会明确提示检查视觉模型配置。应用不通过模型名称猜测视觉能力。

### 写作技能

点击面板顶部书本按钮打开「技能管理」。内置 **ELI5 通俗解释、Mermaid 图表、清晰简洁的写作、Markdown 说明文档、团队沟通文档、Markdown 协作写作** 六个技能，随原生程序内置，无须另外安装 CLI。团队沟通采用 Anthropic 官方 `internal-comms`；协作写作采用 MarkText 自主编写的精简 `markdown-coauthor`。

- 默认「技能 · 自动选择」：模型先看启用技能的名称和用途，需要时才通过工具读取正文、参考资料。
- 输入框上方可指定本次对话使用的技能；发送时只预加载明确指定的技能正文。
- 「导入 SKILL.md」从系统文件选择器导入整个技能文件夹中的文本资料；支持查看内容、启停和删除导入副本。技能配置保存在应用配置目录，重启后保留。
- 源码、固定版本、许可证和自定义技能格式详见 [AI_AGENT_SKILLS.md](AI_AGENT_SKILLS.md)。

## 数据和权限

- API Key 保存到操作系统凭据库（Windows Credential Manager、macOS Keychain、Linux Secret Service），普通设置仅保存地址和模型。Linux 需要可用且已解锁的 Secret Service。凭据库不可用时明确报错，不降级为明文存储。
- 密钥按规范化后的完整基础地址隔离；更换服务不会把旧服务的密钥发送给新地址。保存的密钥不会回传界面，留空保留，专用删除按钮可移除当前服务的密钥。
- 首次模型请求包含该文档的会话消息、附加文档的名称/行数/字节数以及启用技能的名称/用途。文档正文和未指定技能的正文按工具请求加载。聊天仅在窗口内存保留，关闭窗口后清空。未附加文档时模型仍会收到本次对话已有的消息。
- 工具白名单：`read_document`、`search_document`、`propose_edit`、`read_skill`、`read_skill_file`。文档工具只能操作已附加的不可变快照；技能工具只能读取本轮启用技能包内的文本。无通用文件系统、Shell 或联网搜索工具。模型不能直接应用或保存修改。
- 修改在 Rust 和前端各验证一次，要求原文精确且唯一匹配，并限制在附加范围内。文档 ID 和整篇内容快照必须仍匹配，才允许应用。
- 每窗口最多一个生成任务，最多 10 轮、每轮 8 个工具调用、每轮响应 2 MiB；整个任务最多 300 秒。聊天输入最多 240 KB，本地文档快照最多 2 MB，两者单独计量；每次发往模型的序列化消息最多 512 KB（图片数据按上述独立预算计量）。按行读取最多 200 行/48 KB，全文读取最多 240 KB，更长文档可分段读取。
- 取消会终止正在等待的网络请求；错误、截断或取消时不保留该轮未确认的修改。HTTP 仅允许回环地址，其余服务必须 HTTPS；不跟随重定向，不把服务返回的原始错误或凭据写入日志/界面。
- AI 回复的 Markdown 经过 DOMPurify 白名单处理，不加载图片、脚本或其他远程资源。

## 代码与验证

- 后端：`src-tauri/src/commands/agent/`（配置/凭据、SSE 解析、工具执行、任务管理）。
- 前端：`src/stores/agent.ts`、`src/components/agent/`。IPC 由 `tauri-invoke.ts` 和 `tauri-bridge.ts` 管理。
- 单元测试覆盖选区范围、冲突保护、会话隔离、取消竞态和晚到事件。Rust 测试覆盖 UTF-8/SSE 分片、截断流、角色注入、权限边界及真实回环 HTTP 的多轮工具交互。
- 浏览器端到端测试使用模拟模型传输层，真实运行 Vue、Muya、CodeMirror、审阅、应用/撤回和撤销，以及设置、错误、停止、主题、窗口适配。
- 2026-09-13 验证：230 项前端单元测试、80 项 Rust 测试、30 项浏览器测试通过；前端构建和 ESLint 通过。独立应用标识的 Windows 调试构建在真实 WebView2 中通过原生 IPC、系统凭据保存/读取/删除、连接测试、多轮工具调用、修改审阅/应用/撤回和取消测试，模型服务为临时回环 HTTP 服务。测试凭据已删除，测试进程已退出。
- 本地预览构建位于 `output/agent/MarkText-Agent-Preview.exe`，使用 `com.marktext.rs.agent-preview` 应用标识；它是单独的调试预览程序，不是安装包。界面截图与测试记录位于 `output/agent/`。这些生成文件不进入 Git。
- 没有使用真实云服务密钥进行付费调用。兼容性测试不代表所有供应商/模型都支持这些功能；可使用设置内的连接测试验证自己的服务。

2026-09-15 / v0.5.0 验证：232 项前端单元测试、88 项 Rust 测试和 7 项 Agent 浏览器测试通过。回环 HTTP 测试确认普通回答不发送文档/技能正文，技能与参考文件可按需加载，局部编辑不会发送无关段落；隔离目录测试覆盖技能导入、持久化、重名/大小限制和读取边界。中文、英文、日文及窄面板/深色主题截图已检查。独立标识的 Windows WebView2 预览通过六个技能的原生 IPC、启停持久化、`internal-comms` 参考资料读取及 `markdown-coauthor` 局部修改建议测试；系统文件选择器已打开，但电脑控制授权超时，选择文件并完成导入这一步未验收。未使用真实云模型，也未逐一实机验收各平台安装器。

当前范围是单篇文档写作 Agent，不包含整个工作区自动改写、联网检索、MCP 扩展或跨窗口永久聊天记录。
